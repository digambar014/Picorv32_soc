🚀 **UART Implementation & Simulation in Verilog**

As part of my digital design work, I implemented a **UART communication module from RTL** and verified its functionality through simulation.

### 🔹 UART Implementation
• UART Transmitter (TX)  
• UART Receiver (RX)  
• Baud-rate generation  
• Serial data transmission and reception  
• 8-bit data communication  
• Start and stop bit handling  

### 🔹 Verification

I created a simulation environment to verify the UART functionality and analyzed the resulting waveforms to ensure that the transmitter and receiver correctly handle serial data.

The simulation helped me understand how UART works at the **RTL level**, including:

**Parallel Data → Serialization → Serial Transmission → Deserialization → Parallel Data**

One of the most useful parts of the process was debugging the design by observing the actual TX/RX waveforms rather than relying only on RTL code.

### 🛠️ Technologies
**Verilog | UART | RTL Design | Digital Design | Simulation | Waveform Analysis**

This was a good hands-on exercise in understanding how a commonly used communication peripheral is actually implemented at the hardware level.
